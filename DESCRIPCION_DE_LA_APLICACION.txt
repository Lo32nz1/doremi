DOREMI - DESCRIPCION DE LA APLICACION
=====================================

PRESENTACION
------------
DOREMI es una aplicacion para organizar, crear y leer canciones con acordes.
Esta pensada para musicos que quieren tener sus canciones a mano, ordenarlas
para ensayos o presentaciones y consultar un afinador desde el mismo lugar.

FUNCIONES PRINCIPALES
---------------------
- Biblioteca musical: permite elegir una carpeta y buscar canciones en
  formatos ChordPro (.chord, .pro, .chopro, .chordpro y .txt).
- Estudio: organiza las canciones por carpeta y permite abrirlas en un lector
  con acordes y letra.
- Lector: ofrece controles para cambiar el tono y el tamano de la letra.
- Historial: muestra canciones abiertas recientemente y estadisticas de uso.
- Setlists: permite crear listas para ensayos o presentaciones, agregar
  canciones, cambiar su orden y recorrerlas en secuencia.
- Afinador: escucha el sonido por el microfono y ayuda a afinar guitarra,
  bajo, ukelele con afinacion reentrante y violin. Permite fijar una cuerda
  objetivo y muestra si la nota detectada esta alta, baja o afinada. Considera
  afinada una desviacion de hasta 10 cents y suaviza las lecturas de audio.
- Interfaz adaptable: se ajusta a celulares, tablets y pantallas de escritorio.
- Preferencia de tema claro u oscuro.

TECNOLOGIA
----------
La aplicacion esta desarrollada con Flutter y Dart. Usa almacenamiento local
para preferencias, historial y setlists. El afinador requiere permiso para usar
el microfono. La version Android se puede entregar como archivo APK.

EJECUTAR DESDE EL CODIGO FUENTE
-------------------------------
Con Flutter y el SDK de Android instalados:

  flutter pub get
  flutter run

CREAR UN APK PARA PROBAR EN ANDROID
-----------------------------------
Desde la carpeta del proyecto:

  flutter build apk --release

El APK se genera en:

  build/app/outputs/flutter-apk/app-release.apk

Para probarlo, se puede copiar el archivo al telefono Android e instalarlo.
Al abrirlo, Android puede solicitar permiso para instalar aplicaciones desde
esa fuente y DOREMI solicitara acceso al microfono cuando se use el afinador.

Para publicar en Google Play se debe configurar una clave de firma release
propia; el proyecto esta preparado actualmente para pruebas y entregas de
evaluacion.
